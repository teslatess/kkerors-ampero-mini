What changes

  • A dedicated Mode 3 with two assignable presets, A and B.
  • Select a preset with a short footswitch press or a tap on its screen tile.
  • Hold a screen tile to assign a preset using the native list, BACK and SAVE.
  • Independent A/B tile colors and a global BUTTON COLOR setting.

These are two separate presets. Gapless switching is not added. Gold and Orange differ on screen but use the same physical LED ring mask.

Before installation

  1. Back up your presets in Ampero Editor and save your original IR and Sound Clone files separately.
  2. Keep the original V2.2 firmware for reverting.
  3. Build the file on this page, then install it using a compatible Ampero Editor and the official Hotone instructions.
  4. Do not disconnect power or USB while flashing.

Check the stock modes and audio first, then Mode 3, preset assignments and persistence after restarting. To revert, use the original V2.2 and the official Hotone procedure; recovery from this build has not been confirmed on hardware.
